## How To Create a Follow-Up Session (Without Changing the Previous Outcome)

This guide explains how to start a new “follow-up” round when you have additional questions or need improved answers. A follow-up session **does not automatically change** the previous session’s outcome (Successful/Unsuccessful).

### Prerequisites

- You can open an existing session in the application.
- You can see the **Outcome Status** panel on the session page.

### Step-by-Step Instructions

1. Open the session you want to continue.
2. Find the panel titled **Outcome Status**.
3. Click **Create Follow-Up Session**.
4. In the window titled **Create Follow-Up Session**, go to **New Questions \***.
5. Type your new questions:
   - Enter **one question per line**, or
   - Paste a **numbered list** (for example: “1. …”, “2. …”).
6. Click **Create Follow-Up Session**.

### Expected Results

- A new session opens (the next “round”) with your new questions ready to process.
- The new session “remembers” the previous round and uses it as context for improved answers.
- The previous session’s outcome **stays the same** unless you change it manually.

### Troubleshooting

- **I don’t see “Create Follow-Up Session”**: The button appears when the outcome is **Pending** or **Unsuccessful**. If the session is marked Successful, you may need to leave it as-is or start a new session instead.
- **I clicked “Create Follow-Up Session” but nothing happens**: Check for an error message on the page, then try again.
- **My questions were rejected**: Make sure you entered at least one non-empty question in **New Questions \***.

### Additional Information

- **Marking the outcome is manual**:
  - Click **Mark as Successful** if the answers worked.
  - Click **It didn’t work** if the answers did not work as expected.
- **Tip**: Use follow-ups for additional clarifications or missing details—this creates a clean “Round 2 / Round 3 …” history.
